How to use these notes

  1. Read in order, page 1 to page 4. Each lecture builds on the one before. Page 1 gives the vocabulary the rest depends on.
  2. Every topic has the same parts: the idea in one line, a plain explanation with the analogy used in class, a diagram, a worked example, a "don't confuse" box, the AWS equivalent, and questions.
  3. Do the "Check yourself" questions before opening the answers. Click a question to reveal its answer. If you get it wrong, re-read that section.
  4. Stuck? Use the "Watch" box at the end of each lecture. Every video link was checked to be live when these notes were made, and many topics include a Hindi-English option (Gate Smashers). The last link in each box is a YouTube search in case a video is removed later.
  5. Press "Mark as revised" on a lecture when you finish it. Ticks appear on this page and are remembered in this browser.
  6. Finish with the cheat sheet and its numericals drill.
  • Delay and throughput sums (L/R, d/s, bottleneck)
  • Comparison tables: OSI vs TCP/IP, TCP vs UDP, GBN vs SR, HTTP versions, ALB vs NLB, POP3 vs IMAP
  • Ordered sequences: TCP handshake, TLS handshake, DNS resolution
  • cwnd traces through slow start and loss
  • CIDR: hosts in a prefix, sizing a prefix, finding a network address

Things to know about these notes

  • Source. Built from the 16 lecture PDFs in the CLASS folder, following the mid-sem syllabus and the course plan. Examples, numbers, and analogies are the ones from the slides wherever the slides had them.
  • The DNS lecture (Lecture 7) had no PDF in the folder. That section is written from the syllabus, the DNS recap in Lecture 9, and the textbook.
