Topologies: star = cheap, easy, single point of failure at the centre. Mesh = most resilient, most expensive. Hybrid = mix; real networks. Trade-off: cost vs resilience.

Switching: circuit = reserved path, guaranteed, wasteful when idle. Packet = shared on demand (statistical multiplexing), store-and-forward, efficient and resilient, no guarantees.

Lectures 10–11

Reliability, flow control, congestion control → full notes

Reliability tools: checksum (detect damage) · ACK/NAK (confirm) · timeout (detect loss) · retransmission (fix) · sequence numbers (order, duplicates).

Checksum: add the chunks → wrap any carry back in → flip all bits. Receiver adds everything; all 1s = OK.

REST: resources (URLs as nouns) · HTTP methods as CRUD · statelessness. Client–server = central always-on server. P2P = every peer is both.

HTTPS = HTTP + TLS. Goals: confidentiality, integrity, authentication. Asymmetric (public/private key pair, slow) bootstraps a symmetric session key (one key, fast). Certificate = domain ↔ public key, signed by a CA. Chain: leaf → intermediate → root. MITM is defeated by certificate validation. ACM = free auto-renewed certificates attached at a load balancer (TLS termination).

DNS: runs before TCP/TLS, UDP port 53. Hierarchy: Root → TLD → Authoritative. Recursive = resolver does the legwork and returns the answer. Iterative = servers return referrals. Caching with TTL is why changes propagate slowly.

Route 53 policies: Simple (one answer) · Weighted (split by %) · Latency-based (fastest Region) · Failover (standby on health-check failure) · Geolocation (by user's location).

CDN: edge servers near users; pull (fetch on first request) vs push (upload in advance); DNS steers users to the nearest edge. AWS: CloudFront + Edge Locations.

Practice

Ten-minute numericals drill

1. A 2,500-byte packet on a 5 Mbps link. Transmission delay?

20,000 bits ÷ 5,000,000 = 4 ms.

2. A 4,000 km fibre link. Propagation delay?

4,000,000 ÷ 2 × 10⁸ = 20 ms.

3. Path links: 100, 25, 40 Mbps. Time to download a 50 MB file?

Bottleneck 25 Mbps. 50 MB = 400 Mb. 400 ÷ 25 = 16 s.

4. Full mesh of 12 routers: how many links?

12 × 11 / 2 = 66.

5. Page with 1 HTML + 8 images: RTTs for non-persistent vs persistent HTTP?

Non-persistent 9 × 2 = 18. Persistent 1 + 9 = 10.

6. Client SYN seq = 500; server SYN-ACK seq = 900. Both ack numbers?

SYN-ACK carries ack = 501. Final ACK carries ack = 901.

7. GBN, N = 4, 8 packets (0–7), only packet 2 lost once. Total transmissions?

Window at timeout holds 2, 3, 4, 5 → 4 re-sent. 8 + 4 = 12. (Selective Repeat: 9.)

8. cwnd = 1, ssthresh = 16, no loss. cwnd after 7 RTTs (list them)?

1, 2, 4, 8, 16, 17, 18.

9. cwnd = 30: (a) three duplicate ACKs, (b) timeout. New cwnd and ssthresh?

(a) cwnd 15, ssthresh 15. (b) cwnd 1, ssthresh 15.

10. 10.20.30.100/27: network, broadcast, usable hosts?

Block 32 → blocks 0, 32, 64, 96, 128. Network 10.20.30.96, broadcast 10.20.30.127, 30 usable (.97–.126).

11. Prefix for 120 hosts? For 2,000 hosts?

120 → 2⁷ − 2 = 126 → /25. 2,000 → 2¹¹ − 2 = 2,046 → /21.

12. Stop-and-wait: Tframe = 5 ms, Tprop = 10 ms. Utilization?

5 ÷ (5 + 20) = 20%.
